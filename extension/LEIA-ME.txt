Nexus YouTube+ v2.3.5


ATUALIZAÇÕES PELO GITHUB
A versão instalada consulta o manifesto público em https://raw.githubusercontent.com/tarcisioferraz/Nexus-Youtube-/main/extension/manifest.json ao iniciar o Chrome e a cada 6 horas. Também é possível clicar em “Verificar atualizações” nas configurações. Quando a versão remota for superior, o Chrome mostra uma notificação que abre as versões oficiais do GitHub.

IMPORTANTE: o repositório precisa ter o manifesto atualizado para cada nova versão. Esta extensão está instalada por “Carregar sem compactação”, então o Chrome não instala arquivos novos sozinho: é preciso baixar a versão no GitHub, substituir a pasta local e clicar em Recarregar em chrome://extensions.

INSTALAR
1. Extraia este ZIP em uma pasta.
2. Abra chrome://extensions e ative o Modo do desenvolvedor.
3. Clique em Carregar sem compactação e selecione a pasta gif-comentarios-youtube.
4. Abra o YouTube. Não é necessário configurar nada nem inserir chave de API.
5. Nos comentários, use o botão GIF para pesquisar ou cole um link direto de GIF.

PESQUISA SEM CHAVE
A pesquisa usa páginas públicas do GIPHY e pode falhar se o site mudar ou bloquear o acesso. Colar um link direto de GIF continua sendo uma alternativa.

LIMITAÇÃO
O YouTube aceita texto nos comentários comuns. A extensão transforma links de GIF em imagens apenas localmente para quem tem a extensão instalada; pessoas sem ela verão o link.

Versão 1.8.3: o GIF agora é inserido como uma miniatura no próprio cursor do editor (inclusive no meio do texto). Inclui reconhecimento de media.giphy.com e media2.giphy.com em vídeos comuns e Shorts, sem buscar/navegar o frame do YouTube.

Versão 1.8.4: ao inserir um GIF encostado em texto, a extensão acrescenta automaticamente um espaço antes e/ou depois dele.

Versão 1.8.5: em comentários de vídeos longos, os GIFs usam a mesma estrutura de imagem do YouTube (ytCoreImageHost / ytwCommentImageAttachmentViewModelImage) e também são detectados dentro de yt-attributed-string.

Versão 1.8.6: a leitura do comentário publicado agora alcança as camadas Shadow DOM abertas do YouTube. Isso permite converter o link em GIF após publicar também nos vídeos longos.

Versão 1.8.8: reconhecimento explícito de URLs diretas como https://media.giphy.com/media/ID/giphy.gif, tanto no texto como no redirecionamento do YouTube. A imagem publicada usa o carregamento HTTP(S) padrão do navegador.

Versão 1.9.2: corrige o ícone de troféu usando uma imagem SVG própria da extensão, compatível com a barra lateral compacta.

Versão 1.9.5: ícone de troféu inserido diretamente no item da barra lateral para aparecer fora do shadow DOM do yt-icon; campo de pesquisa limpo após abrir resultados; menu ampliado para 16 modalidades.

CONFIGURAÇÕES — VERSÃO 2.2.3

- Personalize o fundo do YouTube com uma cor ou URL de imagem, ajuste a opacidade e escolha o escopo.

Versão 2.3.0: corrigida a abertura das configurações. O botão agora solicita ao service worker da extensão que abra options.html, em vez de tentar abrir diretamente uma URL chrome-extension:// a partir do YouTube, que pode ser bloqueada pelo Chrome.


Versão 2.3.1: adiciona checagem de atualização pelo manifesto remoto do GitHub, aviso de nova versão, verificação manual nas configurações e link para releases.

Versão 2.3.1: verificador de atualização pelo manifesto do GitHub, notificação quando uma versão maior é publicada, botão de verificação manual e link para as versões oficiais.

Versão 2.3.2: em vídeos longos em tela cheia, os atalhos Configurações e Nexus YouTube+ (incluindo painel, botão flutuante e botão Plus) ficam automaticamente ocultos. A detecção acompanha tanto o modo nativo do navegador quanto a classe de tela cheia do player do YouTube.

Versão 2.3.3: o fundo do modo "Página e área do vídeo" agora cobre as duas camadas principais de conteúdo (página e player), sem modificar o cabeçalho. O modo "Todo o site" aplica a imagem também ao cabeçalho e aos menus.

Versão 2.3.4: ao publicar um comentário em vídeo longo, os GIFs inseridos como miniatura são convertidos para o link real antes do envio. Isso garante o mesmo funcionamento dos Shorts: miniatura enquanto escreve e GIF grande após publicar.

Versão 2.3.5: uma camada fixa de fundo agora fica atrás de toda a interface do YouTube. A cor ou imagem escolhida aparece inclusive nas áreas em que o YouTube não oferece fundo próprio, enquanto vídeos, textos e controles continuam acima dela. O envio do GIF em comentário de vídeo longo passa a encontrar também o botão interno “Comentar” e tenta renderizar o GIF logo após a publicação.

Limitação do YouTube: comentários comuns não aceitam anexar ou enviar arquivo GIF. Sem hospedar o arquivo em um serviço externo, o comentário precisa publicar a URL do GIF; a extensão a mostra como imagem somente para quem usa a extensão.


Nexus YouTube+ v2.3.6: consulta o manifesto público no GitHub ao iniciar e a cada 15 minutos. Quando detecta uma versão superior, mostra um aviso central no YouTube com os botões Atualizar e Mais tarde. A atualização é confirmada pelo usuário e o Chrome ainda exige a substituição/recarregamento manual para instalações descompactadas.


Versão 2.3.9: adiciona Luz Ambiente dinâmica opcional no player do YouTube, com controle de intensidade nas configurações. O efeito é processado localmente no navegador.


Versão 2.4.0 — Coração de pesquisas: novo botão em formato de coração ao lado da barra de pesquisa do YouTube. Versão 2.4.1 — Correção: a barra de controles do player (tempo, legendas CC, configurações, barra de progresso) podia desaparecer porque o CSS da luz ambiente forçava z-index nos controles mesmo com a luz desligada. As regras foram removidas.

Versão 2.5.0 — Atualização automática e configurações preservadas.
1) ID fixo: o manifest agora tem um campo "key", então o Chrome sempre reconhece a extensão como a mesma, mesmo se a pasta mudar de lugar. Suas configurações, recentes e favoritos não zeram mais nas próximas atualizações. (Na primeira vez que você instalar a 2.5.0 o ID muda uma única vez, então as configurações voltam ao padrão uma última vez.)
2) Botão Atualizar: ao clicar em "Atualizar" no aviso (ou em "Atualizar automaticamente" nas configurações), a extensão baixa os arquivos novos do GitHub, grava na pasta da extensão e se recarrega sozinha. Na primeira vez você escolhe a pasta da extensão (a mesma carregada em chrome://extensions); depois é só clicar. Para funcionar, a pasta "extension" do GitHub precisa estar com a versão nova.
NÃO remova a extensão do Chrome para atualizar: remover apaga as configurações.

Versão 2.6.0 — Auto update e página de agradecimento.
1) Auto update (Configurações > Atualizações do Nexus): quando LIGADO, a extensão verifica o GitHub a cada 5 minutos e sempre que você abre o YouTube; se houver versão nova, atualiza sozinha, sem perguntar, e avisa por notificação (depois dê F5 nas abas). Quando DESLIGADO, nada é atualizado sozinho e o aviso com botão "Atualizar" continua funcionando a cada 15 minutos.
   Ao ligar pela primeira vez, uma janela pede para você escolher a pasta da extensão (a mesma de chrome://extensions). É feito uma vez só. Se o Chrome esquecer a permissão (por exemplo depois de reiniciar), a extensão volta a mostrar o aviso normal e um clique em "Permitir e atualizar" resolve.
2) Ao desinstalar, o Chrome abre uma página de agradecimento. Ela fica em docs/obrigado.html no GitHub. Ative em GitHub > Settings > Pages > Branch main, pasta /docs, para o endereço https://tarcisioferraz.github.io/Nexus-Youtube-/obrigado.html funcionar.
